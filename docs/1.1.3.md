# 鸿米家 1.1.3-OS 更新说明

> 版本号：**1.1.3-OS**　Version Code：**1000130**

---

## 新增功能

### 主题色流光

外观设置的主题色下面新增一个「主题色流光」开关（**默认开启**）。

打开后，按压沉浸光感卡片时，手指底下会出现一团柔光：

- **跟着手指走** —— 手指在卡片上滑动、或者按住不放让页面滚动，光都跟着手指，
  不会黏在卡片上不动；
- **颜色取自你的主题色**，不再是系统默认的白光；
- 光只落在被按的那张卡片里，到卡片边缘就被玻璃收住，**不会漏到旁边的卡片上**。

底部标签栏的流光也一起跟着主题色走。把这个开关关掉，两处都回到系统默认的白光。

#### 卡片流光触感（默认关闭）

主题色流光下面另有一个「卡片流光触感」开关：

- **关闭（默认）**：**按压卡片不出现任何流光**；
- **开启**：按压卡片出现完整的跟手流光——手指底下那团跟手光斑，
  以及映照到卡间缝隙的环境光。

它只影响卡片，**底部标签栏的流光不受影响**。

### 新增两个浅色主题色

主题色列表新增：

| 名称 | 色值 |
| --- | --- |
| 涟漪粉 | `#FAD6E4` |
| 流萤绿 | `#88E4D4` |

这两个颜色很浅，直接拿来当底色用会看不清上面的字，因此全局做了一次适配：
凡是主题色底上压文字的地方（首页房间与排序芯片、智能页分类芯片、场景的重复日、
各处主色按钮、主题色色块上的对勾等），字色改为按主题色的深浅**自动在黑字与白字之间选**。
选浅色主题色时不会再出现看不清的白字。

### 默认主题色

主题色列表的第一项仍然是「鸿蒙蓝」，它同时就是默认值：
没设置过主题色的设备、设置读取出问题时，都会回到这一档。

## 问题修复

### 修复切换标签页后列表不回顶部

在标签页之间切换时，列表会停在上次浏览的位置，而不是回到顶部。
这个问题从 1.1.0 起一直存在，长期只能靠首页顶栏的「列表回正」按钮手动处理。

现已修复：**切换标签页后，该页列表会自动回到顶部**，不再需要手动干预。

### 修复更换主题色后底部标签栏的高亮色不跟着变

换主题色后，底部四个标签里选中那个图标的颜色会停在上一套配色，要重启才生效。
现在会立即跟随当前主题色。

### 修复耗材中心的卡片文字看不清

耗材中心的卡片用的是浅色玻璃底，但上面的文字一直是白色，内容基本读不出来。
现在改为深色文字，分隔线与进度条底槽也一并改成与其它页面一致的浅灰。

### 清理早期残留的米家蓝配色

早期代码里把米家蓝（`#3379B7`）连它的各种半透明变体一起写死在不少地方。
切主题色后它们不会跟着变，表现为开关、卡片描边带着一层对不上号的旧蓝，
和当前主题色明显不是一个色系。这一版把它们全部清掉了。

## 说明

### 标签栏高亮的更新时机

标签栏高亮现在**在切换动画结束后**更新，而不是在动画开始时就切换到新标签。

如果开着「首页平滑切换」（300 毫秒动画），高亮会随之滞后约 300 毫秒。
把该项关闭则没有这个现象。

### 关于卡片边缘的反光

按压时，光目前只作用在被按的那张卡片里，相邻卡片的边缘不会出现反光。

（试过让光「照到」旁边的卡片：给每张卡片都加一层跟随光源的边缘高光。
效果达到了，但滚动时掉帧严重，已整体回退。实现方式与回退原因记在
[`ThemeColor.md`](ThemeColor.md) 的 §5.9，后续要用更省性能的做法重做。）
