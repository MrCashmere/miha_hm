# 鸿米家 1.1.2-OS 更新说明

> 版本号：**1.1.2-OS**　Version Code：**1000120**

本次新增两个主题色相关的开关，并把深色模式改成可跟随系统，另修复了几处观感问题。

---

## 新增功能

### 卡片沾色

「外观设置」主题色下方新增开关。打开后所有卡片会沾上一层淡淡的主题色，
整体配色更统一；关闭则恢复中性卡片。

### 高权限自定义主题色

默认情况下，页面背景的淡色调只跟随内置主题色，自己输入的颜色不会铺到整页背景上。
打开这个开关后，自定义颜色也会参与，并且同样按原有算法调淡。

### 深色模式改为三选一

深色模式从「开 / 关」改为 **跟随系统 / 浅色 / 深色** 三个选项，默认跟随系统。

之前一旦拨动过那个开关，就只能固定在浅色或深色上，
**再也没有办法回到「跟随系统」**（只能靠重置所有设置救回来）。现在随时可以选回来。

---

## 问题修复

### 修复设备详情页开关卡片按压时变色

点击设备详情页的开关卡片时，卡片会蒙上一层颜色 —— 主题色偏粉时整张卡会变成粉色。
按压反馈不应该改变卡片颜色，已移除。

### 修复开启卡片沾色后卡片变大

新加的沾色层尺寸计算有误，会把卡片撑高、比原来大一圈。已修正。

### 修复房间筛选等按钮背后的阴影

房间筛选、设备排序、智能页分类切换这几个小按钮背后会多出一层阴影。已移除。

  首页顶栏提供了「列表回正」按钮作为临时手段，该问题仍在排查中。
