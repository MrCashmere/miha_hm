# 鸿米家 1.1.0-OS 更新说明

> 版本号：**1.1.0-OS**　Version Code：**1000100**

本次更新幅度较大，新增了三个页面、一套全局主题色，并把整个界面的视觉统一重做了一遍。

---

## 新增功能

### 主题色

在「外观设置」里可以更换全局强调色：

- 内置预设色，点一下即可切换；
- 也支持输入任意色值新增自己的颜色，新颜色会加进色块列表并立即生效；
- 自己新增的颜色可以单独删除；
- 开关、滑杆、按钮、输入光标、图标、选中态等全部跟随主题色变化，切换后立刻生效，不需要重启。

### 耗材总览

新增耗材页面，把各个设备的耗材余量汇总在一起，按剩余比例排序，快用完的会标红提醒，不用再逐个点进设备查看。

### 本地智能（场景）

新增场景编辑页面，可以在本机创建自动化场景和定时任务，只在本机执行、不依赖云端。

### 设备管理

新增设备管理页面，可以批量整理设备：

- 给设备改名；
- 把设备移动到别的房间；
- 置顶常用设备；
- 把不用的设备从本机列表中移除。

### 家庭消息

新增消息标签页，集中查看家庭消息，已读状态会保留。

### 首页搜索与排序

首页顶部新增搜索框，可按设备名称、型号或房间搜索；旁边的排序按钮可在「在线优先 / 按名称 / 按房间」之间切换。

### 其他新增

- **房间排序**：房间列表可以上下移动调整顺序，调整结果会保存。
- **按键触感反馈**：点击按钮时带有轻微的振动反馈。

---

## 体验优化

- **设备详情页重做**：改为分区卡片式布局，控件改为单列排列，小屏和长名称设备不再被截断；新增数据趋势图。
- **沉浸光感覆盖到全应用**：卡片、按钮、从底部弹出的面板统一使用同一套玻璃质感，观感一致。
- **设置页整理**：新增「首页概览卡片」开关，可以收起首页的检索、房间筛选和一键关灯区域；重置项补全。
- **设备图标**：根据设备型号自动匹配图标，不同类型设备的图标区分更清楚。
- **离线可用**：设备能力数据在本机缓存，网络不稳定时设备详情页不再整页空白。
- **备份与恢复**：导出与恢复流程进一步完善。

---

## 问题修复

以下几项都是 1.0.7-OS 上就存在、本次修好的问题：

- 修复「全局沉浸光感」开关打开后看不到效果的问题：卡片和按钮上的光感此前一直没有真正生效。
- 修复从底部弹出的面板底色发白、把光感效果盖住的问题。
- 修复云端接口调用失败的问题（请求头格式有误）。
- 修复登录时换取访问令牌失败的问题（请求参数格式有误，且会把正常响应误判为失败）。
- 修复登录授权的跳转地址不可用的问题。
- 修复局域网设备发现不可用的问题（网络套接字没有正确初始化）。
- 修复局域网数据读取错乱的问题（读取范围不对，数据被截断或混入多余内容）。
- 修复多台设备状态互相串扰的问题（不同设备的状态没有分开记录，同名状态会互相覆盖）。
- 修复登录信息保存不完整的问题（账号标识与后续云端请求所需的密钥没有存下来，导致云端功能不可用）。
